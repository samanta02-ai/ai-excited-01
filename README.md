A golden phoenix bursts out of an erupting volcano, wings wide, trailing
fire — while teal and violet aurora ribbons burn across a storm sky
above it. The image was made to hit the judge in one look: a huge
central bird, lava below, light above, everything in motion. The bird
fills the frame, so the idea still lands when the image is shown small.

## The program

`main.py` is plain Python 3.13 standard library. It copies the shipped
`entry.png` into the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`). Run it twice and the bytes are identical.

## Files

- `entry.png` — the image, a true 256-colour PNG, 1024×1024
- `main.py` — the copy program
- `LICENSE` — MIT
