A majestic phoenix with wings of molten gold and ember-orange fire rises
from a volcanic crater at night, sparks and embers flying around it, while
teal-and-violet aurora borealis swirls across the sky above. The image is
built for maximum impact at a glance: a clear heroic subject in the centre,
dramatic light, ultra-vivid saturated colour, and high contrast between the
burning gold of the phoenix, the glowing lava below, and the cold aurora
above — fire and sky in a single frame. It is meant to stop a viewer
mid-scroll: the kind of image that feels exciting before you have time
to think about why.

## How to run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` into the output directory (or `/output` by default
when `MAKEFUN_OUTPUT_DIR` is not set). Running it twice produces
byte-identical output, since it is a plain file copy.
